AI ব্যবহারের নতুন নিয়ম (Pedagogical Learning Rules)

AI ব্যবহার করা খারাপ নয়; সমস্যা হয় যখন AI তোমার হয়ে প্রতিটি সিদ্ধান্ত নেয় এবং তুমি নিজে চিন্তা করার সুযোগ পাও না।

১. নিজে চেষ্টা (Self Effort)

Problem বুঝে input/output, example ও logic খাতায় লিখবে; অন্তত ২০-৩০ মিনিট নিজে সমাধান করার চেষ্টা করবে।

২. ৩টি ধাপে Hint (Tiered Hints)

আটকে গেলে AI-কে বলবে: “একটি hint দাও, full solution নয়।” ৩ ধাপে concept, logic, ও corner case বুঝবে।

৩. Code Debug (Error Finding)

নিজে code লিখবে, compile error ও runtime message পড়বে এবং কারণ খুঁজে বের করার মাধ্যমে দক্ষতা বাড়াবে।

৪. Verify & Self Test (যাচাই)

AI ছাড়া নিজে code লিখতে পারা, explain করা এবং modify করতে পারা হলো আসল শেখার মানদণ্ড।

AI ব্যবহারের নতুন নিয়ম ও শেখার পদ্ধতি

How to effectively learn programming with AI without cheating your brain

AI ব্যবহার করা খারাপ নয়। সমস্যা হয় যখন AI তোমার হয়ে প্রতিটি সিদ্ধান্ত নেয় এবং তুমি নিজে চেষ্টা করার সুযোগ পাও না।

১. নিজে চেষ্টা

Problem বুঝে input/output, example ও logic লিখবে; অন্তত ২০-৩০ মিনিট চেষ্টা করবে।

২. ৩টি Hint

আটকে গেলে AI-কে বলবে: “একটি hint দাও, full solution নয়।”

৩. Code Debug

নিজে code লিখবে, run করবে, error পড়বে এবং কারণ খুঁজবে।

৪. Verify

নিজের solution কাজ করার পরে AI review নেবে; ভুল নিজে ঠিক করবে।

নিজের শেখা যাচাই

কোনো topic নিজের শেখা বলে ধরবে যখন তুমি AI ছাড়া:

  • (১) code নিজে লিখতে পারো
  • (২) code প্রতি লাইনে explain করতে পারো
  • (৩) প্রশ্নকর্তা চাইলে code modify করে নতুন লজিক বানাতে পারো।

AI-কে যেভাবে বলবে
