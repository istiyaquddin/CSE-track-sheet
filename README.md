# CSE-track-sheet

Problem Solving Arena & Practice Track Sheet for IIUC CSE Structured Programming (C Programming).

## 🚀 Features

- **100+ Practice Problems**: Complete roadmap covering:
  - **Data Types & I/O (D1 – D27)**: Variables, format specifiers, precision, arithmetic operators, Gauss summation, math functions.
  - **Conditionals & Branching (C1 – C28)**: `if-else`, compound logic, nested conditionals, intervals, quadratic formulas.
  - **Loops & Iteration (L1 – L50)**: `while`, `for`, `do-while`, primes, GCD/LCM, Fibonacci, sequence checking, Collatz series.
  - **Switch Case (Switch 1 & 2)**: Multi-way decision branches.
  - **Animation (Animation 1)**: Console graphics and animations using C.
- **3-Tier Pedagogical Hints**:
  - 💡 **Hint 1: Concept & I/O Breakdown**
  - ⚙️ **Hint 2: Step-by-Step Algorithmic Logic**
  - ⚠️ **Hint 3: Edge Cases, Corner Cases & Precision Pitfalls**
- **Verified C Solutions**: Tested C code solutions for every problem.
- **Video Class Sessions**: Embedded playlist links for Sessions 0 to 17 plus assignment solve classes.
- **Progress Tracking**: LocalStorage state persistence for solved problems and custom notes.

## 🧠 AI ব্যবহারের নতুন নিয়ম (Pedagogical Learning Rules)

> *Al ব্যবহার করা খারাপ নয়; সমস্যা হয় যখন AI তোমার হয়ে প্রতিটি সিদ্ধান্ত নেয় এবং তুমি নিজে চেষ্টা করার সুযোগ পাও না।*

1. **নিজে চেষ্টা (Self Effort)**: Problem বুঝে input/output, example ও logic খাতায় লিখবে; অন্তত ২০-৩০ মিনিট একা চেষ্টা করবে।
2. **৩টি Hint (Tiered Hints)**: আটকে গেলে AI-কে বলবে: *“একটি hint দাও, full solution নয়।”*
3. **Code Debug (Debugging)**: নিজে code লিখবে, run করবে, error পড়বে এবং কারণ খুঁজবে।
4. **Verify & Review (যাচাই)**: নিজের solution কাজ করার পরে AI review নেবে; ভুল নিজে ঠিক করবে।

### নিজের শেখা যাচাই
কোনো topic নিজের শেখা বলে ধরবে যখন তুমি AI ছাড়া:
1. Code লিখতে পারো
2. Code explain করতে পারো
3. Code modify করতে পারো

### AI Prompt for Tutoring
```text
আমি নিজে solve করতে চাই. Full solution দেবে না. প্রথমে একটি hint দাও. আমার logic ভুল হলে কোথায় ভুল হচ্ছে বুঝতে সাহায্য করো, কিন্তু code লিখে দিও না.
```
